Mở dự án
Mở phần mềm VS Code, chọn File > Open Folder và trỏ tới thư mục chứa mã nguồn của bạn (ví dụ: D:\hi\cineforge).
Thiết lập không gian làm việc chính cho dự án.

Cài đặt thư viện
Mở Terminal tích hợp trong VS Code và chạy lệnh:
* cd merged
* npm install
Tải xuống đầy đủ các gói thư viện cần thiết (node_modules) cho dự án.
